

# 🛒 Online Shopping Cart (Java)

## 📌 Project Overview

The **Online Shopping Cart** is a console-based Java application developed as part of the **Syntecxhub Java Internship Program**.
This project demonstrates how to build a simple shopping cart system using **Java Collections Framework**, focusing on efficient data handling and user-friendly interaction.

---

## 🎯 Project Objectives

* Use **ArrayList** and **HashMap** effectively
* Implement core shopping cart features
* Manage item quantities and prices efficiently
* Provide a smooth, menu-driven user experience

---

## 🛠 Technologies Used

* **Java (Core Java)**
* **Java Collections Framework**

  * `ArrayList`
  * `HashMap`
* **Object-Oriented Programming (OOP)**

---

## 🧠 Collection Usage Explanation

| Collection                 | Purpose                         |
| -------------------------- | ------------------------------- |
| `ArrayList<Item>`          | Store list of items in the cart |
| `HashMap<String, Integer>` | Store item quantities           |
| `HashMap<String, Double>`  | Store item prices               |

This design ensures **fast access, easy updates, and efficient total calculation**.

---

## ✨ Features

✔ Add items to the cart
✔ Increase quantity for existing items
✔ View cart contents
✔ Calculate total price
✔ Clear menu-driven prompts
✔ Clean exit from the program

## ▶ How to Run the Project

1. Clone the repository:

   ```
   git clone https://github.com/your-username/Syntecxhub_Online_Shopping_Cart.git
   ```
2. Open the folder in any Java IDE (VS Code / IntelliJ / Eclipse)
3. Compile the files:

   ```
   javac *.java
   ```
4. Run the program:

   ```
   java Main
   ```
